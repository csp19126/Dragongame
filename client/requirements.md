## Packages
framer-motion | Complex animations for slot reels and win celebrations
lucide-react | Icons for UI elements
canvas-confetti | Celebration effects for big wins
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging Tailwind classes safely

## Notes
- "VnSlot" requires a vibrant, red/gold aesthetic typical of Vietnamese luck/culture.
- Slot machine logic is handled on the backend (`/api/game/spin`), frontend just animates the result.
- Authentication is required for gameplay.
- Bilingual support (EN/VI) will be implemented with a React Context.
